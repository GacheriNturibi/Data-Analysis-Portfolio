# GIS and Remote Sensing Projects

This folder contains my portfolio of **GIS and Remote Sensing projects**, covering Earth Observation, geospatial analysis, and applied data science.  

Each project is self-contained with its own **README** (or write-up) detailing workflows, outputs, and insights. This top-level README serves as a landing page to explore them all.

---

## Projects

- **[Quantifying Above-Ground Biomass (AGB)](https://github.com/GacheriNturibi/Data-Analysis-Portfolio/tree/main/GIS%20and%20Remote%20Sensing/Above%20Ground%20Biomass%20Modelling)**  
  Estimation of AGB using vegetation indices derived from Sentinel-2 imagery, integrated with ML regressors.  

- **[Dynamics of Irrigated Farmlands](https://github.com/GacheriNturibi/Data-Analysis-Portfolio/tree/main/GIS%20and%20Remote%20Sensing/Dynamics%20of%20Irrigated%20Farmlands)**  
  Multi-year vegetation dynamics analysis for Mashuru, Kenya, using indices like NDVI, EVI, SAVI, MSAVI, and OSAVI.  

- **[Farms Accessibility Analysis](https://github.com/GacheriNturibi/Data-Analysis-Portfolio/tree/main/GIS%20and%20Remote%20Sensing/Farms_Accessibility_Exercise)**  
  GIS-based buffer analysis around primary roads to assess accessibility of farm plots in Nyanza District, Rwanda.  

- **[Urban Heat Island (UHI) Analysis – Nairobi](https://github.com/GacheriNturibi/Data-Analysis-Portfolio/tree/main/GIS%20and%20Remote%20Sensing/Urban_Heat_Island_(UHI)_Analysis_%26_Mitigation_Planner_(Nairobi))**  
  Mapping UHI patterns in Nairobi using Landsat-8 LST, NDVI, and OSM land-use data, with seasonal analysis.  

- **[Predicting Malaria Prevalence in Kenya](https://github.com/GacheriNturibi/Data-Analysis-Portfolio/tree/main/GIS%20and%20Remote%20Sensing/Predicting-Malaria-Prevalence-in-Kenya)**  
  Machine learning and geostatistics to predict malaria prevalence based on climatic, environmental, and socio-economic factors.   

- **[ArcGIS StoryMap: Mapping Outliers & Unusual Geographic Facts](https://github.com/GacheriNturibi/Data-Analysis-Portfolio/tree/main/GIS%20and%20Remote%20Sensing/StoryMaps)**  
  An interactive StoryMap highlighting extreme places, unusual borders, and quirky geographic outliers.  
  *(Work in progress — more fascinating case studies to be added!)*
